## Speakers: Submit Your Resources

After the event, accepted speakers are encouraged to share their materials here. This makes your work discoverable by the community long after the event.

### How to submit

1. **Fork** this repository
2. **Edit `README.md`** and add a row to the Talks table with your session info
3. **Open a Pull Request** with the title: `Add talk: [Your Talk Title]`

### What to include

In your PR / table row, please provide as many of the following as you have available:

| Field | Description |
|---|---|
| **Title** | Full title of your talk |
| **Speaker(s)** | Your name(s) and a link to your GitHub, LinkedIn, or personal site |
| **Type** | `Session` (25 min) or `Workshop` |
| **Topics** | One or more topic tags from the list above |
| **Slides** | Link to slides (Google Slides, Speaker Deck, PDF, etc.) |
| **Video** | Link to recording once published on [KCD Texas YouTube](https://youtube.com/@kcdtexas) |
| **Code** | Link to a GitHub repo, gist, or other code resource |

### Example table row

```markdown
| 1 | Observability at Scale with OpenTelemetry | [Jane Doe](https://github.com/janedoe) | Session | `#observability` `#open-source` | [Slides](https://speakerdeck.com/...) | [Video](https://youtube.com/...) | [Code](https://github.com/...) |
```
